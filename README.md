# Kentucky Weather Observations

A point-based map showing weather observation stations across the state of Kentucky, created as part of the [30 Day Map Challenge](https://www.30daymapchallenge.com) to practice GIS skills.

## How to View

This project was built in QGIS and exported as a web map. Click the deployment link below to view it in your browser:

👉 [View the Map](https://kaliehyde.github.io/Kentucky-Weather-Observations/)

## Tools

- [QGIS](https://qgis.org) (open-source desktop GIS)
- [30 Day Map Challenge](https://www.30daymapchallenge.com)
